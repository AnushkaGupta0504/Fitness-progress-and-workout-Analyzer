# FitnessAI Enhanced

Full-stack AI fitness tracker with Gemini chatbot, heart rate monitor, step counter, activity tracker, and enhanced charts.

## New Features
- Activity Tracker page: live HR monitor, step counter ring, 7-day history, simulate live data
- Dashboard: heart rate + steps stats, gradient charts
- Analytics: steps trend chart + all charts enhanced with gradients
- AI Coach: powered by Gemini 1.5 Flash (your Bot.py API key integrated)

## Setup
```
cd backend && npm install
cp .env.example .env   # add MONGODB_URI and GEMINI_API_KEY
node server.js
```
